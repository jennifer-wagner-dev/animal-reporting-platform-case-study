# My Contribution

My main responsibility in the team project is the frontend development of the application.

I implemented most of the Vue.js frontend, including the application views, reusable UI components, routing, frontend state management and the organisation-specific workflows.

The authentication store, validation logic and photo upload component were implemented by other team members and are therefore not included in my contribution.

## Frontend Development

I implemented the majority of the application's views, including:

- Home view
- Found animal reporting view
- Found animal result view
- Missing pet reporting view
- Login and registration views
- Organisation dashboard
- Organisation case overview
- Organisation case detail view
- Organisation capacity management
- Organisation settings
- Organisation workflow for new incoming cases

These views form the main user-facing workflows of the application.

## Reusable Components

I created several reusable Vue components used throughout the application:

- `AppHeader.vue`
- `AppFooter.vue`
- `MainNavBar.vue`
- `OrganizationSidebar.vue`
- `CapacityCard.vue`
- `IncomingCaseCard.vue`

The goal was to keep recurring UI elements reusable and maintain a consistent structure across the different views.

## Routing

I implemented the application's frontend routing using Vue Router.

The router connects the different reporting, account and organisation views and provides the navigation structure for the application.

## State Management

I worked with Pinia stores to manage frontend state for the organisation-related workflows.

My contributions include stores for:

- organisation data
- organisation capacity
- organisation cases

The authentication store was implemented by another team member.

## Data & Frontend Models

I created frontend data structures used by the application, including data for:

- animal species
- found-animal results
- organisation cases

These structures are used by the views and components to display and process application data consistently.

## UI & Styling

I worked on the overall frontend structure and visual implementation of the application using Vue.js and Vuetify.

This included:

- page layouts
- navigation
- dashboard elements
- cards
- forms
- organisation-specific interfaces
- responsive and reusable UI elements

## Frontend–Backend Integration

As part of the frontend work, I integrated the user interface with the backend functionality required by the different workflows.

This includes displaying and processing data for animal reports and organisation cases and adapting the frontend to the agreed API structures.

## Team Collaboration

The project is developed by a three-person team.

My main area of responsibility is the frontend, while other team members work on areas such as backend development, authentication, validation and file upload functionality.

This required regular coordination regarding:

- API structures
- expected request and response data
- shared data models
- feature requirements
- integration between frontend and backend
